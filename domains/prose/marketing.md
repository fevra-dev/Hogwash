# Marketing Copy and Blog Posts

Part of domains/prose/. Load alongside core/structural-patterns.md.

## Default Structures to Break

- **Problem-agitate-solve (PAS) as the only structure:** fine occasionally, a tell when it's the default.
- **Value proposition stacking:** 5–7 benefits listed with no hierarchy. Human copywriters choose one lead benefit.
- **Power verbs with no information content:** transform, unlock, discover, boost, skyrocket, they imply action while saying nothing.
- **CTA inflation:** multiple calls to action in one paragraph.

## What Human Marketing Copy Does

- Specific numbers: "Nango used this to migrate 47 repos in 3 days" not "leading companies use this"
- Stark contrasts: "You could read 47 migration guides. Or install one package."
- Honest limitations: "This cuts migration time in half" (specific) not "dramatically improves efficiency" (vague)
- Starts with the punchline, not the setup: "Codemods automate 70% of migrations. This gets you to 95%." not "In this article, we will explore..."
- Conversational asides that show lived experience: "You could write a 400-line script for this. We did. It broke on Unicode."

## Subheadings as Statements

Not "Background": "Why the existing approach fails"
Not "Results": "Query time dropped from 847ms to 12ms"
Not "Introduction": "Stripe's migration guide is 12,000 words. This gets it down to 200 lines of code."
*(English convention, see lenses/language.md before applying to non-English content.)*
