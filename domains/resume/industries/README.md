# Resume Industries — Index

The generic layer in domains/resume/patterns.md (results-driven, proven track record, spearheaded, leveraged) applies to any resume in any field. Each file in this folder is the next layer down: what AI slop looks like inside a specific profession, once the generic layer is already handled. Load the relevant file alongside domains/resume/patterns.md. Skip the rest.

## Current Files

- **tech.md**: IT, software development (including full-stack), cybersecurity
- **administrative.md**: administrative and office support roles
- **healthcare.md**: nursing, allied health, clinical roles
- **finance-sales.md**: finance, accounting, and sales, grouped because they share one defining tell

## Extending to a New Industry

1. Find the field's own canonical tell: the one phrase that shows up as the flagged bad example across multiple independent sources, not just one blog's opinion.
2. Identify where a named category substitutes for a named specific thing in this field, a tool, a client, a product, a technique.
3. Check whether the field has its own version of "best practices," a phrase that signals confident-sounding emptiness specifically within that profession's jargon.
4. Watch for numeric camouflage: a precise-looking number attached to a noun that's still doing no real work.
5. Note any field-specific fabrication risk, a status, credential, or claim that's unusually easy to overstate without the candidate noticing.

Give the new file its own name (marketing.md, finance.md, healthcare.md...) and add it to the list above and to SKILL.md's dispatch note.
